📑 Analytical Detection Methodology

Scientific foundations, mathematical models, feature engineering taxonomy, and countermeasures against adversarial social media manipulation.

1. Executive Overview & Problem Definition

Automated social media accounts ("bots"), sybil networks, and astroturfing campaigns distort public consensus, facilitate phishing scams, and degrade user trust across modern digital platforms. This project introduces a multi-tier analytical detection architecture combining static metadata indicators, non-stationary temporal Poisson dynamics, linguistic entropy, and graph topological metrics.

2. Mathematical Formulation of Detection Signals

A. Follower-Following Reputation Index ($R$)

Legitimate human profiles cultivate bi-directional social graphs. Mass-following spam bots exhibit extreme asymmetry:

R = Followers / (Followers + Following + ε) where R ∈ [0, 1]. R < 0.05 indicates acute asymmetric bot behavior.

B. Shannon Entropy of Alphanumeric Handles ($H(X)$)

Synthetic usernames generated via PRNG or batch scripts exhibit distinct character entropy relative to natural human phonetic phonemes:

H(X) = - Σ [ P(x_i) · log₂(P(x_i)) ] where P(x_i) is the probability frequency of character x_i in handle string X.

C. Inter-Arrival Time Variance (Poisson Process Analysis)

Organic human interactions are modeled by bursty Pareto or non-homogeneous Poisson processes with high inter-arrival interval variance $\sigma^2(\Delta t)$. Conversely, automated cron scripts emit events at near-zero variance intervals ($\Delta t \approx \text{const}$):

σ²(Δt) = (1 / (N - 1)) · Σ (Δt_i - μ_Δt)² Clockwork threshold: σ²(Δt) < 0.15 triggers automated scheduling penalty.

D. Circadian Sleep Rhythm Entropy

Human biological circadian rhythms dictate 6–8 hour periods of near-zero posting activity. The circadian entropy metric measures the uniform dispersion of events across 24 hourly buckets:

CircadianEntropy = - (1 / log₂(24)) · Σ [ p_h · log₂(p_h) ] for h ∈ [0, 23] Continuous 24/7 posting yields CircadianEntropy → 1.0 (Automated Farm).

3. Explainable AI (SHAP-Inspired Local Attribution)

To maintain transparency for trust and safety operators, the decision engine computes linear additive feature attributions:

g(z') = φ₀ + Σ φ_i · z'_i where φ_i represents the positive or negative risk delta contributed by signal i.

4. Defensive Countermeasures & Sybil Mitigation

Based on the analytical scores produced by CyberSentry AI, platforms deploy graduated countermeasures:

  • Score < 30%: Verified Authentic. Unrestricted platform access.
  • Score 30% - 65%: Suspicious. Enforce dynamic proof-of-work, rate limits, and SMS/TOTP step-up verification.
  • Score > 65%: High Risk. Shadowban feed distribution, trigger CAPTCHA challenges, and submit to human forensic review.
  • Score > 90%: Malicious Sybil Node. Immediate cryptographic API token revocation and IP cluster quarantine.
